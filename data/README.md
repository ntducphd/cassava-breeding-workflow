# Synthetic reference outputs

`expected_s6/Supplementary_Table_S6_Simulation_Contrasts.csv` contains the seven paired contrasts in Supplementary Table S6. `expected_s6/Supplementary_Table_S6_Simulation_Replicates.csv` contains eight values per contrast. The saved programme and deployment records used to calculate them are in `analysis/results/`.

Columns and model assumptions are defined in `docs/METHODS_EN.md` and the calculation script. Uncertainty intervals describe founder-replicate variation under the synthetic generator. These files contain no measured cassava trial, farm or UAV-image observations.
